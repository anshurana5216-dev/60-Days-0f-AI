# Football Intelligence Hub

An AI-powered Football Intelligence Dashboard that combines FIFA World Cup predictions, football knowledge assessment, personality analysis, and interactive data storytelling into a single engaging experience.

---

##  Project Overview

Football Intelligence Hub is an innovative analytics project designed to transform football data into actionable insights and personalized experiences.

The dashboard leverages AI-driven reasoning, structured prompt engineering, and visual analytics to provide:

* FIFA World Cup 2026 Predictions
* Football IQ Assessment
* Messi vs Ronaldo Personality Match
* Interactive Data Visualizations
* Football Intelligence Profile Generation

This project demonstrates how sports analytics, AI, and user engagement can be combined to create an immersive football intelligence platform.

---

##  Features

### FIFA World Cup 2026 Prediction Engine

Analyze historical trends, team performance, player strength, and tournament patterns to generate:

* Most Likely Winner
* Runner-Up Prediction
* Dark Horse Nation
* Players to Watch
* Confidence Scores
* Risk Analysis

---

###  Football IQ Quiz

Evaluate football knowledge through a multi-level quiz.

Outputs include:

* Football Awareness Score (0-100)
* Fan Classification
* Knowledge Strengths
* Weak Areas
* Learning Recommendations

Classification Levels:

* Beginner Fan
* Casual Viewer
* Football Follower
* Football Enthusiast
* Football Expert

---

###  Messi vs Ronaldo Personality Match

A personality assessment inspired by football legends.

Measures:

* Ambition
* Discipline
* Leadership
* Creativity
* Competitiveness
* Confidence
* Teamwork
* Decision-Making Style

Outputs:

* Messi Compatibility %
* Ronaldo Compatibility %
* Personality Analysis
* Football Archetype

---

###  Football Personality Archetypes

The system identifies one of the following archetypes:

* Creative Playmaker
* Relentless Competitor
* Tactical Visionary
* Quiet Leader
* Fearless Attacker
* Strategic Commander
* Consistent Performer
* Big-Match Specialist
