#  Upload Image Puzzle Game

A responsive browser-based puzzle game built with HTML, CSS, and JavaScript. Users can upload any image from their device, choose a difficulty level, and play an interactive drag-and-drop puzzle.

## Features

* Upload custom images
* Multiple difficulty levels (3×3, 4×4, 5×5)
* Drag-and-drop puzzle pieces
* Mobile touch support
* Live timer and move counter
* Correct piece highlighting
* Win detection
* LocalStorage leaderboard
* Responsive design

## How to Run

1. Download the project.
2. Open `upload_image_puzzle_game.html` in your browser.
3. Upload an image.
4. Select a difficulty level.
5. Start solving the puzzle!

## Learning Outcomes

* DOM Manipulation
* Canvas Image Processing
* Drag & Drop Interactions
* Touch Event Handling
* Local Storage Management
* Frontend Game Development
