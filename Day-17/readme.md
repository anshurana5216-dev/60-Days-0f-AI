#  Vehicle Cost & Fuel Analysis Dashboard

A modern, responsive, data-driven dashboard designed to analyze vehicle ownership costs, fuel efficiency, maintenance expenses, environmental impact, and fuel-type comparisons using CSV datasets.

Built using pure HTML, CSS, JavaScript, and SVG visualizations without any external libraries.

---

## Overview

The Vehicle Cost & Fuel Analysis Dashboard transforms raw vehicle data into actionable insights through interactive visualizations and analytical metrics.

The dashboard automatically processes vehicle datasets and provides comparisons across multiple fuel types including:

* Petrol
* Diesel
* CNG
* E85
* EV

Users can evaluate operating costs, fuel efficiency, maintenance requirements, emissions, and long-term ownership expenses.

---

##  Features

###  Dynamic KPI Metrics

* Fuel Cost per KM
* Maintenance Cost per KM
* CO₂ Emission per KM
* Refuel / Recharge Time
* Monthly Ownership Cost

###  Fuel Comparison Analysis

Compare all supported fuel types based on:

* Cost Efficiency
* Fuel Economy
* Environmental Impact
* Refueling Convenience
* Long-Term Operating Cost

### Environmental Insights

* CO₂ Emission Tracking
* Fuel-wise Carbon Footprint Analysis
* Sustainability Comparison

###  Vehicle Aging Analysis

Analyze how vehicle age impacts:

* Running Cost
* Maintenance Cost
* Emissions

Age Categories:

| Category | Age Range |
| -------- | --------- |
| New      | 0–2 Years |
| Mid-Life | 3–5 Years |
| Aged     | 6–9 Years |
| Old      | 10+ Years |

###  E85 Fuel Evaluation

Specialized E85 Analysis:

* Pump Saving Percentage
* Running Cost Penalty
* Break-even Fuel Price
* Environmental Benefits
* Overall Fuel Score
